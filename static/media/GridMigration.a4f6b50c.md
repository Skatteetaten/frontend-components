**Fra @skatteetaten/frontend-components v1 (designsystem-legacy) til Designsystemet v2.x**

## Endringer i funksjonalitet:

Grid-komponenten ble i sin tid opprettet for å kunne gi grid-funksjonalitet til eldre nettlesere, for eksempel Internet Explorer 11. Moderne nettlesere støtter allerede tilsvarende grid-funksjonalitet gjennom CSS Grid layout, og vi anbefaler å bruke dette som erstatning for Grid-komponenten i legacy.

## CSS Grid layout

CSS Grid layout er allerede godt dokumentert på https://www.w3schools.com/css/css_grid.asp
